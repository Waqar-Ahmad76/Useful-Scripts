# 🛠️ Useful Scripts

A personal collection of Bash scripts for Linux written as I am learning DevOps and Cloud Engineering. 

## 📋 Script Index

| Script | Category | Description |
|---|---|---|
| [`server-stats.sh`](./server-stats.sh) | Monitoring | Analyzes core server performance metrics (CPU, RAM, Disk, Top processes) and OS info. |
| [`log-archiver.sh`](./log-archiver.sh) | System Maintenance | Compresses and archives given log directories into timestamped tarballs with an automated audit log. |

*(More scripts will be added to this index as the repository grows.)*

## 🚀 Quick Start

To use any script in this repository, clone it to your local machine and make the scripts executable.

**1. Clone the repository:**
```bash
git clone [https://github.com/Waqar-Ahmad76/Useful-Scripts.git](https://github.com/Waqar-Ahmad76/Useful-Scripts.git)
cd Useful-Scripts
```

**2. Make the script executable:**
```bash
chmod +x server-stats.sh
```

**3. Run the script:**
```bash
./server-stats.sh
```
*(Note: Run `sudo ./server-stats.sh` if you want to view restricted security logs, like failed SSH login attempts).*
